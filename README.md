# Organizador de Fotos

Proyecto en Python para leer los metadatos de fotografías,
mostrar la información y crear copias renombradas según
la fecha y hora de captura.

## Estado del proyecto

En desarrollo.

## Requisitos

- Python 3.11+
- Windows

## Estructura

- `fotos_entrada/` — fotografías originales.
- `fotos_salida/` — fotografías procesadas.
- `src/` — código fuente.
- `tests/` — pruebas.
